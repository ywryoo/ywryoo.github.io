맥을 쓰다 보면 기본 키보드 단축키가 살짝 아쉬울 때가 있습니다. 특히 윈도우 키보드나 로지텍 MX Keys S 같은 외부 키보드를 함께 쓰는 경우, 한영 전환이나 원격 환경에서의 키 매핑이 생각보다 불편하게 느껴질 수 있습니다.

저는 이 불편함을 줄이기 위해 Karabiner-Elements를 사용해 키보드 설정을 조금 바꿔서 사용하고 있습니다.

## 오른쪽 Command 키를 한영 전환 키로 사용하기
가장 먼저 설정한 것은 오른쪽 Command 키를 한영 전환 키처럼 쓰는 것입니다.

Karabiner에서 오른쪽 Command 키를 F18 키로 매핑합니다. 그다음 macOS의 시스템 설정에서 키보드 단축키로 들어가, 입력 소스 전환 키를 F18로 지정합니다.

이렇게 설정하면 실제로는 오른쪽 Command 키를 누르지만, macOS에서는 F18 키가 입력된 것으로 인식합니다. 결과적으로 오른쪽 Command 키를 자연스럽게 한영 전환 키처럼 사용할 수 있습니다.

설정 흐름은 대략 다음과 같습니다.

Karabiner에서 오른쪽 Command 키를 F18로 매핑
macOS 키보드 단축키 설정에서 한영 전환 키를 F18로 지정
오른쪽 Command 키를 눌러 한영 전환
이 방식의 장점은 기존 Command 키 조합과 충돌을 줄이면서, 한영 전환 전용 키처럼 쓸 수 있다는 점입니다.

## Citrix Viewer에서의 키 매핑
업무용으로 Citrix Viewer를 사용할 때도 키보드 매핑이 필요했습니다. 로컬 맥 환경과 원격 윈도우 환경에서 키 동작이 다르게 느껴지기 때문입니다.

Citrix Viewer가 실행 중일 때는 Karabiner 설정을 따로 적용해서 다음처럼 매핑했습니다.

왼쪽 Option 키 → 오른쪽 Command 키
왼쪽 Command 키 → Alt 키
이렇게 설정하면 Citrix Viewer 안에서는 왼쪽 Option 키가 한글 전환 키처럼 동작하고, 왼쪽 Command 키는 원격 환경의 Alt 키처럼 사용할 수 있습니다.

즉, 맥에서는 맥답게 쓰고, Citrix 안에서는 윈도우 환경에 맞게 키가 동작하도록 나눈 셈입니다. 원격 환경을 자주 오가는 경우 이 차이가 꽤 크게 느껴집니다.

MX Keys S 설정은 Logi Options에서 조정
나머지 키보드 설정은 Karabiner보다는 Logi Options에서 MX Keys S 설정을 바꿔가며 조정하려고 합니다.

특히 지금은 전원 키를 활용해서 화면을 끄는 방법을 연구 중입니다. 맥에서 화면 잠금이나 디스플레이 끄기를 빠르게 실행할 수 있으면 작업 흐름이 더 편해질 것 같아서, 이 부분은 조금 더 테스트해볼 예정입니다.

## 마무리
정리하면 현재 키보드 세팅의 핵심은 다음과 같습니다.

Karabiner로 오른쪽 Command 키를 F18로 변경
macOS 입력 소스 전환 단축키를 F18로 지정
오른쪽 Command 키를 한영 전환 키처럼 사용
Citrix Viewer 실행 시 별도 키 매핑 적용
MX Keys S의 나머지 키 설정은 Logi Options에서 조정
맥의 기본 키보드 설정만으로는 살짝 부족한 부분이 있지만, Karabiner와 Logi Options를 함께 사용하면 꽤 만족스러운 키보드 환경을 만들 수 있습니다. 특히 한영 전환과 원격 데스크톱 키 매핑 때문에 불편함을 느끼는 사람이라면 한 번쯤 시도해볼 만한 설정입니다.
